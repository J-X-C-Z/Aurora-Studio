# Windows 后端更新 · 2026-11-13

本版以当前 Windows 主树的只读快照为输入，增量合入已发布的图库管理版本。前端图库、持久化身份、RAW 方向修复、节点图类型和相同画质的拖动预览均保留。

## 更新范围

- 源图解码增加并发请求合并与缓存复查，避免同时请求同一图像时重复解码；预览继续保持拖动和静止同分辨率、同像素质量。
- 增加 RAW 解码降级原因与稳定错误类别，前端连接嵌入预览的提示；机身 ICC 选择支持已安装 profile 的严格匹配，歧义时拒绝猜测。
- 扩展 C1 目录/会话只读导入、蒙版几何、参数映射与预设往返、胶片曲线错误报告；人像修饰记录只读解析，不等于恢复原厂人像渲染。
- 导出配方增加输出锐化参数与名称模板、元数据处理、可选 HEIF 编码器探测和结构化错误。取消导出连接到后端任务状态；已经开始的文件可能完成写入。
- 增加 Windows WIA 相机详情和设置、ICC 显示/软打样基础接口、HEIF 辅助图像信息解析。具体可用性取决于本机库、模型与设备。

## 人像能力

- 人像算法独立为 `aurora-pixcake` crate，保留 CPU、CUDA 与 Metal 的 typed API；引擎通过 `portrait_backend` 再导出。
- `ImageEngine::portrait_capabilities()` 返回阶段状态、所需输入、统一桥支持及 automatic=false。代码可调用、像素阶段可执行和自动滑块生效是不同状态。
- `render_portrait_stage()` / `export_portrait_stage()` 连接纹理平滑 PF8069 负值分支、三类皱纹阶段及颈纹修复回贴，另有通用蒙版组合。其他家族继续使用对应 typed module API，缺输入明确拒绝。
- CUDA 皱纹阶段复用调用方会话，并返回真实设备/内核 dispatch；显式 CUDA 请求不偷偷改用 CPU。
- 预览与导出使用同一阶段；导出要求完整源尺寸和 8 位配方，拒绝用低清预览放大或把 RGBA8 冒充 16 位处理。

## 能力边界

- 软打样后端接口保留实验性质；前端继续标记未接通，不能把近似纸白/黑点处理当作原厂印刷模拟。
- HEIF 编码需要可用的 libheif 与 HEVC encoder；本发布包未新增其运行库。HEIF 导入链路仍待整合；JXL/DNG/PSD 原生输出未完成。
- 本轮不包含仍在专用分支的机身默认值 r15。独立人像库已加入发布工作区，并通过 ImageEngine 提供能力查询、显式输入预览和导出；CUDA 像素阶段与 ONNX/TensorRT 推理配置分别记录，Apple 实机不作完成声明。
- HDR/全景、AI 降噪、镜头模糊、节点图并行混合器、Session Trash 物理移入/恢复、目录合并和模板等缺口仍在。
- 编译与合成测试不等于真实相机、真实照片同图、网络盘、断电恢复或 GPU 加速验收。具体命令和结果见 GitHub 发布说明。
