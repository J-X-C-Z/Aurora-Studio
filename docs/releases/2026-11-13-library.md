# Aurora Studio Windows 预览版 · 2026-11-13 图库管理

本版在图库和文件管理上对齐 Capture One 的核心工作流，同时包含 2026-11-13 的 RAW 相机方向修复。

- 新建 Aurora 目录和会话；会话提供 Capture、Selects、Output、Trash 快捷目录，并连接拍摄与导出目标。
- 图库文件夹树、系统文件夹按需浏览、收藏、包含子文件夹、目录同步、定位离线目录和单张原片。
- 照片移动、文件夹移动/重命名、单张与批量重命名、拖放到真实文件夹，均更新原片、XMP、变体身份和调整记录。
- 项目、组、相册和智能相册持久化；项目内智能相册限定项目成员，拒绝循环和嵌套项目。
- 导入支持原位引用或复制、日期目录、安全命名、备份、XMP 配套复制、重复检测和逐文件取消，拒绝覆盖同名文件。
- 离线记录保留评级、关键词、集合与调整，使用最近缓存预览浏览；重新连接后恢复原片处理。
- 目录索引升级到 schema 2，保留 schema 1 备份；损坏索引或集合文件阻止文件管理写操作。
- 修复竖幅 NEF 因 EXIF 方向与预览 fallback 不一致而横置的问题。

这些数字只测文件管理和目录持久化，不包含 RAW 解码、缩略图生成或 GPU 推理。

验证结果：app 44 项、engine 517 项、预览契约 2 项通过，0 失败；engine 30 项忽略。Windows 原生 Release 构建、834 文件 SHA256 校验、合成会话真实窗口和 Capture 快捷位置切换通过。

限制：目录废纸篓是逻辑移除，不永久删除原片；Session Trash 未实现物理移入/恢复；离线缓存不按当前调整重新渲染，也不放大到全分辨率；整个文件夹跨盘移动明确报错；批量重命名暂不允许交换或仅修改大小写。真实相机、CUDA/TensorRT、网络盘和断电中断恢复未在本版验收。
