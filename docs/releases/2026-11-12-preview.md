# Aurora Studio Windows 预览版 · 2026-11-12

整合 2026-11-12 Levin 前端快照与已验证的 Windows 后端快照。此发布独立于正在继续开发的 Windows 主工作树。

- 新前端：节点编辑器、挑片、快速页签、示波器、第二查看器、欢迎页与触控布局。
- 保留 Windows RAW、色阶/曲线、颜色编辑器、蒙版持久化及 WIA 后端。
- 拖动和静止预览保持相同视口分辨率及像素质量；修复 270 度自动旋转返回值，连接本机胶片曲线与当前会话的 C1 风格导入。
- 默认测试与私有参考资产分离；附开发规范和 Windows CI。

验证：不带私人样本的源码通过全目标检查；app 11、engine 495、集成测试 2 通过（总计 508），0 失败，28 项忽略。Windows 原生 Release 构建通过。真实窗口合成图回放的 120 次调整最终显示最新值、Final 质量及一次撤销记录。该回放不是性能对比基准。

运行：解压 Windows x64 包并启动 aurora-studio.exe，保留 libraw/ 和 licenses/。包含动态 LibRaw 0.23 与所需运行库及许可。

限制：HDR/全景、AI 降噪、镜头模糊、ICC 软打样、取消导出与部分原生导出格式尚未接通；节点混合器仍按串行列表渲染，导出包含未连接节点；部分 HE* NEF 使用内嵌预览。AI 功能需本机合法模型与 ONNX Runtime。本版未验收真实相机、CUDA/TensorRT 推理加速或原厂同图对拍。

代码采用 MIT；第三方组件适用各自许可。不包含 Capture One 模型、ICC、预设、校准表或私人照片。
