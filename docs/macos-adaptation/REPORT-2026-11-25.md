  并记录 `z6iii_linear`；一次性警告说明 Z6III 颜色阶段仍仅 Windows。
- `raw_cache.rs`：macOS `~/Library/Caches`；路由/缓存键随 `z6iii_feature` 变化。

### AI（Mac-E）
- `aimask/ort.rs`：macOS 真实 dylib 候选（Frameworks / `.1.23.2` / `.1` / `.dylib`）、
  平台无关错误、`~/Library/Caches/.../onnxruntime`、`Provider::CoreMl`（仅按导出符号可选）、
