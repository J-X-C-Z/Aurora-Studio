# 人像 147：接手清单与验收边界

这份交接把能独立复用的工具、尚未集成的半成品以及历史桌面性能候选分开。**本次交付不改变 `main` 的桌面行为，也不代表人像 147、零 ORT 或五平台验收完成。** 阅读现有工程从[代码架构导览](CODEBASE-TOUR.zh-CN.md)开始。

## 2. 新基线还差什么

- 本 PR 从 `main` 的 `74179b3c13e151c8aaaa98f2b4736e65b7a64ecf` 起步；旧性能分支的公开头是 `4a05bff13f2a9055a46e521686fe7a3b3d833e50`。人像任务的指定提交是 `7056ada950aae10ead4161222a0e90d3286c1ddb`，不是这两个公开提交。按 SHA 获取返回 `not our ref`，公开 Git 对象与源码归档查询为 404。
- 对累计补丁，确认了 **31 个文件中的 27 个**目标 Git blob。未确认的是 `crates/app/src/tools/portrait.rs`、`crates/engine/src/aimask/ort.rs`、`crates/engine/src/mock/process.rs`、`crates/engine/src/portrait_face_input_stage.rs`。公共兼容树上的上下文匹配不等于目标内容一致，不提交这 27 件的部分覆盖，也不将附件保存到公开仓库。
- 兼容树仅完成离线 workspace 元数据解析。默认 `cargo check` 在 `portrait_plump_onnx.rs:395` 报 `error[E0624]: method is_native_only is private`，资产双态验收没成立。这个结果描述的是兼容覆盖，不是指定提交本身的缺陷。
- 按公开清单去重为 **147 个主效果 + 6 条测试缺口**；累计补丁的已确认注册表中，主效果命中 95 项，另有 `PF109/110` 两个子控，尚缺 52 个主效果。注册并不证明执行或变像素。
- 五个随补丁提供的纯 CPU 模块曾在缺私产、模型和 ORT 的环境分开使用 `rustc --edition=2021 --test <源文件> -o <临时测试程序>` 核验：美体核心 36、69 槽桥接 20、眉长 16、长尾 23、丰盈合成 5，共 100/100。此处统计已有源码的合成测试，不把它重报为新增 100 个效果或端到端证明。

## 3. 半成品：不要按完成项合入

| 项 | 保留的结论 | 缺的最后一段 |
|---|---|---|
| A · 注册表 / UI | `PF90032` 应核对眼型遮罩 type 10；`PF30210` 的标量值域须与 0–4 离散读取一致；`PF109/110` 操作两个通道，只由 `PF108` 执行一次 | 只留了范围/阶段测试草稿。注册表存档命令中有 `Unrecognized option: 'j'`，牙齿测试在编译前门遇到 E0624。无完整红绿与真实 UI 证明。脸部几何单位和 147 项对齐仍需验证。 |
| B · 美体 | `PF408` 的入口接受 `Mesh`，实际生产/应用路径需要 `Height`；已写类型矩阵与 408 写入/像素测试草稿。现有姿态适配层区分 Halpe‑26、COCO‑17 与 MediaPipe‑33 | 修复未落入生产路由。干净公开树测试在结束时仍停在编译；23 项、8 类几何载荷和 live 路由均不计通过。 |
| C/D · 后端与着色器 | 探针只验证了原生 Vulkan 上的小型整数融合和 FP32 运算 | CUDA/Metal/WGPU 统一路由、CPU SIMD、QNN 扩展与 147 项三端着色器一致性，均未按新基线验收；旧 DX12 不是 WGPU。 |
| E · 自研模型 | 两张原创 LUT 可复用 | 尚无七类自研权重、可重复训练/导出和生产默认寻址；不要用恒等/空模型填覆盖数。 |
| F · 实拍与平台 | 独立工具可生成合成对照、统计、热图和失败清单 | 还没有同源参考与实拍的 147 项矩阵、24 MP 16 位产品导出、五平台性能、或在该基线上的 CI 门禁。 |

旧性能线后续的三个可用线索也未并入 C4：DX12 的 `ReduceMean` 需要同时处理常量 `axes` 输入和旧属性，不能把未解析的轴当成全张量求均值；合成平均池化过关不代表换输入的完整模型稳定；`prepared → Viewer` 的等待与下一输入相关，通知与重绘的因果还需加安装时戳确认。不要把这些隔离实验的产出补到 C4 的实测分母里。
